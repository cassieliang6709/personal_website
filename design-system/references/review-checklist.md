# Review Checklist

## P0 — must pass

- [ ] The page makes only source-backed claims about shipping status, role, and outcomes.
- [ ] One dominant semantic mode governs the page; accents are not used as arbitrary decoration.
- [ ] The first screen clearly says what the work is, why it matters, and who remains in control.
- [ ] All type, color, spacing, and corner values come from `tokens.css` or a documented alias.
- [ ] Text is readable at 320px and the mobile composition is intentional.
- [ ] Keyboard focus is visible; controls have labels; external links are honest about their destination.
- [ ] Motion has a reduced-motion fallback.
- [ ] Chinese and English versions are both complete and natural.

## P1 — strong quality bar

- [ ] The page contains a concrete artifact, mechanism, or decision—not only claims.
- [ ] A project card communicates state and proof before visual treatment.
- [ ] There is one clear visual interruption, not a page of competing effects.
- [ ] The hierarchy has real contrast: tiny operational labels, normal body, and generous editorial display type.
- [ ] Hover and focus behavior adds clarity without needing animation to explain itself.

## P2 — final polish

- [ ] Page title, description, and social metadata match the visible page.
- [ ] A screenshot still reads as Cassie's work without seeing the logo.
- [ ] The final page answers: What can this person build, and how does she think?
