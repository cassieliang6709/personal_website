# Component Contracts

Components are information patterns, not decoration. Keep their job stable even when the layout changes.

## 1. Site chrome

**Job:** orient without consuming attention.

- Monospace name or handle on the left; a short anchor nav and language control on the right.
- A quiet bottom rule, never a floating glass header.
- On narrow screens retain the language control; collapse anchors only if section navigation is redundant.

## 2. Editorial hero

**Job:** establish a human point of view and a specific technical posture.

- Use an asymmetric two-column layout only when the secondary column proves the point: terminal, state model, artifact, or photo.
- One serif sentence at a time. The lede adds scope; it does not restate the title.
- A small timestamp or status stamp may appear once.

## 3. Proof card

**Job:** make a project legible in under ten seconds.

Required order: `status/type` → `project name` → `outcome` → `one proof/mechanism` → `destination`.

- Use an accent surface only when its semantic color supports the project story.
- Offset shadows are interaction feedback, not permanent decoration.
- A private or unlinked project is a card, not a broken external link.

## 4. State panel

**Job:** describe current work with a boundary.

Required ingredients: a date/status label, a short current focus, and a concrete limit or next step. Prefer a split panel over a generic callout box.

## 5. Trajectory row

**Job:** show progression without treating a career as a startup timeline.

- Date stays quiet and aligned; the event earns the visual weight.
- Each row names a capability gained or a question that became clearer.
- Three to five rows are enough.

## 6. Principle note

**Job:** articulate a belief that appears in the work.

- Use in groups of three only when the ideas are truly parallel.
- A note gets one accent color and one clear sentence; no quote marks or decorative illustration required.

## 7. Text link or action

**Job:** create a calm, explicit next action.

- Underline or background-highlight on hover; do not depend on a faint color shift.
- State destination accurately: `View product`, `Read case study`, `GitHub`, `Email`.
- External destinations get `↗` only when useful contextually.
