# Cassie portfolio

Run `npm install`, `npm run dev -- --port 5175`, and `npm run build` here.

React + TypeScript + Vite. The site has one compact HOME page for products and personal work, plus an ABOUT page for Cassie's résumé. Product details, albums, reading notes, the draggable Lanyard pass, and the illustration archive are React interactions.

Vercel builds this directory from the repository root. The post-build step keeps the existing English site available at `/en/`.
